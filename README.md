# FLAMES : A childhood game of alphabets

Working:
  1. Takes two names as input
  2. strikes off common alphabets in both names.
  3. counts whatever is left, say n
  4. Now counts FLAMES in such a way it starts with F and counts n times. whichever alphabet comes, strike off.
  5. Repeat until one alphabet is left and the judgement is: F-Friends, L-Lovers, A-Affectionate, M-Married, E-Enemies, S-Sister
